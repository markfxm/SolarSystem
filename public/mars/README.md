# Mars surface texture provenance

The local 1K JPEG textures are from **Aerial Rocks 02**, by Rob Tuytel / Poly Haven.

- Asset: https://polyhaven.com/a/aerial_rocks_02
- License: CC0, https://polyhaven.com/license
- `diffuse.jpg`: original Diffuse map
- `nor_gl.jpg`: original OpenGL normal map (linear data)
- `rough.jpg`: original Rough map (linear data)

Downloaded 2026-09-18. The runtime applies a Mars-colored material; original files are unmodified.
These files are served locally; visiting the scene does not contact Poly Haven.
